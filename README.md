# Blingo - Beautiful Bingo Board Creator

A modern, easy-to-use web application for creating beautiful, customizable bingo boards.

## Features

- ✨ **Easy Board Creation** - Click any cell to edit and customize your bingo board
- 🎨 **Style Customization** - Full control over fonts, colors, borders, and decorative elements
- 📐 **Multiple Board Sizes** - Choose from 3x3, 4x4, 5x5, or 6x6 boards
- 💾 **Export Options** - Download your board as PNG or PDF
- 🎯 **Beautiful Design** - Modern, clean interface focused on simplicity

## Getting Started

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

The app will be available at `http://localhost:5173`

### Build

```bash
npm run build
```

## Usage

1. **Customize Your Board**: Use the left panel to adjust styles, colors, fonts, and decorative elements
2. **Edit Cells**: Click on any cell (except the center FREE space) to add your content
3. **Randomize**: Click "Randomize Board" to quickly fill all cells with placeholder text
4. **Export**: Click "Download as PNG" or "Download as PDF" to save your board

## Customization Options

- **Fonts**: Modern, Serif, Monospace, or Handwriting
- **Colors**: Customize text, background, and border colors
- **Borders**: Adjust width, style (solid, dashed, dotted, double), and corner rounding
- **Decorative Elements**: Add stars, hearts, circles, diamonds, or flowers
- **Title**: Customize the board title and size

## Tech Stack

- React 18
- Vite
- Tailwind CSS
- html2canvas (for PNG export)
- jsPDF (for PDF export)
